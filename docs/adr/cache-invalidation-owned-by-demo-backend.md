# 원본과 응답 캐시의 관계는 데모 백엔드가 관리합니다

맥락: 상품 하나의 변경이 상세와 목록·검색 응답에 함께 영향을 주지만, mini-redis는 value의 바이트만 저장하므로 상품 관계를 알 수 없습니다.

결정: 원본 조회·수정과 관련 응답의 무효화는 별도 데모 백엔드가 기존 HTTP 저장·조회·삭제·TTL을 사용해 처리하며, 상품 관계나 백엔드 간 순서 보장 기능을 mini-redis에 추가하지 않습니다.

이유: "백엔드는 우리가 만든 레디스를 정상적 활용한다는 가정을 가지고 만들어야 해."
