# Triage Labels

This repo uses one triage role. It is a `Status:` line in each spec and ticket file, not a GitHub label.

| Label in mattpocock/skills | Label in our tracker | Meaning |
| -------------------------- | -------------------- | ------- |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an agent |

The other four roles (`needs-triage`, `needs-info`, `ready-for-human`, `wontfix`) belong to the `/triage` flow. This repo does not use `/triage`, because the team writes every spec in a grill session. Do not add them.
