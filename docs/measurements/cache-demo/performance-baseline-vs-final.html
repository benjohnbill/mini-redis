mini-redis 성능 테스트 · 기준선과 최종 비교

기준선 d64ae63 → 최종 1a64bd7(#49까지 병합한 main) · 같은 macOS arm64 · SQLite와 PostgreSQL · 버전마다 432회 실행

이 문서의 화살표는 두 종류다. 기준선 → 최종은 코드를 고치기 전과 후의 비교다. off → on은 같은 코드에서 캐시를 껐을 때와 켰을 때의 비교다. 표마다 어느 쪽인지 위에 적었다.

1. 결론

  • 초당 500요청을 보낸 맥 테스트에서 조회 p50은 72개 조건 모두 기준선보다 낮았다. 각 조건에서 캐시를 끈 경우와 켠 경우가 모두 빨라졌다.
  • p50은 이 테스트의 대표 응답 시간을 비교하는 데 쓸 수 있다. p95와 p99는 일부 회차에서 크게 튀어서 개선 판정에서는 뺐다.
  • 상품 상세의 캐시 on p50이 기준선보다 38~64% 낮아졌다. TTL 60초의 고른 상세에서 SQLite는 3.82 → 1.60 ms, PostgreSQL은 5.12 → 2.44 ms다. 같은 조건에서 SQLite의 캐시 HTTP 요청은 회당 19,247 → 2,171~2,193건으로 줄었다.
  • 최종에서 캐시를 켜면 적중률이 99.9~100%인 반복 목록·검색의 p50이 1.92~2.48 ms다. 적중률 50% 이상 조건의 목표는 PostgreSQL 18/18개, SQLite 13/18개가 통과했다. PostgreSQL에서 매번 다른 목록·검색은 캐시 on이 여전히 2.32~8.03 ms 느리다.
  • PR별 지연 감소는 WSL에서 한 단계씩 측정한 기록으로 봐야 한다. #39는 응답을 빨리 보내고, #40·#41은 상세의 캐시 HTTP 요청을 묶는다. 맥에서 관측한 개선 폭에는 여러 PR과 실행 시점 차이가 함께 들어 있다.

캐시를 켜는 게 이득인가: 기준선과 최종

세 무리 각각에서, 같은 버전 안의 캐시 off와 on을 비교한 결과가 기준선과 최종에서 어떻게 바뀌었는지 정리했다. 숫자는 TTL 60초, 조회만 하는 조건의 조회 p50(ms)이고, 화살표는 캐시 off → on이다.

  1. 같은 목록·검색 반복*-repeated* 기준선캐시 on이 빠름 (SQLite 목록 16.01 → 3.03 ms) 최종캐시 on이 빠름 (SQLite 목록 14.70 → 2.23 ms), on p50은 1.92~2.48 ms 기준선부터 이득 · 더 빨라짐
  2. 상품 상세detail-* 기준선SQLite on이 약 2배 느림 (고른 상세 1.95 → 3.82 ms), PostgreSQL 거의 같음 (4.72 → 5.12 ms) 최종SQLite 거의 같음 (1.55 → 1.60 ms), PostgreSQL on이 빠름 (3.73 → 2.44 ms) PostgreSQL은 이득으로 바뀜 · SQLite는 손해가 사라짐
  3. 조건을 바꾼 목록·검색*-varied* · 적중률 0% 기준선모두 on이 느림 (SQLite 목록 16.65 → 18.52 ms, PostgreSQL 검색 28.50 → 47.75 ms) 최종SQLite 손해 거의 없음 (목록 13.49 → 13.17 ms), PostgreSQL 여전히 느림 (검색 15.85 → 23.88 ms) PostgreSQL은 손해가 남음

5. 캐시로서의 성능

여기서는 "캐시를 켜는 게 이득인가"를 본다. 그래서 각 버전 안에서 캐시 on과 off를 비교하고, 그 결과를 기준선과 최종으로 나란히 둔다.

캐시 off     요청 → 앱 → 원본 DB에서 조회 → 응답
캐시 적중    요청 → 앱 → mini-redis에서 응답을 찾음 → 응답
캐시 미적중  요청 → 앱 → mini-redis에 없음 → 원본 DB에서 조회 → 캐시에 저장 → 응답

11.3 부록 · 지도 위 캐시 이득 (on÷off, 기준선 → 최종)

2.2 테스트 지도와 같은 배치에 on÷off를 넣었다. 칸마다 기준선 값(흐린 숫자) → 최종 값이다. 칸 색은 최종 값 기준이다. 숫자는 11.1 결과표의 「on÷off」 열과 같다. on÷off는 캐시 켠 시간 ÷ 끈 시간이다. 0.5면 켜면 절반 시간, 1이면 같고, 1.5면 1.5배 느리다.

  • 0.5 미만 (캐시가 2배 이상 빠름)
  • 0.5~1 미만 (캐시가 빠름)
  • 1~1.2 (조금 느림)
  • 1.2~1.6 (느림)
  • 1.6 이상 (많이 느림)
