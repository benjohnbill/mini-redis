# 05: 느린 클라이언트가 다른 요청을 막지 않는다

**Status:** ready-for-agent

**What to build:** 헤더를 반쯤 보내고 멈춘 클라이언트나 큰 body를 천천히 보내는 클라이언트가 있어도, 다른 서버의 요청은 바로 응답을 받습니다. spec이 4단계로 넘긴 확인이며, 서버 코드는 바꾸지 않고 기능 테스트로 확인만 합니다. 결과가 예상과 다르면 구현하지 말고 팀에 가져옵니다. 결정은 `../spec.md`의 "Q10 M2의 범위"를 따릅니다.

**Blocked by:** 04

테스트 시나리오(팀 확인 2026-11-13). 테스트 이름은 아래 문장을 그대로 씁니다.

- [ ] (기능) 헤더를 반쯤 보내고 멈춘 연결이 있어도 다른 요청은 바로 응답을 받는다
- [ ] (기능) 큰 body를 천천히 보내는 연결이 있어도 다른 요청은 바로 응답을 받는다
- [ ] 끝까지 오지 않는 연결을 mongoose가 언제 닫는지 확인해 `## Comments`에 기록한다. 닫지 않으면 `make verify`가 멈출 수 있으므로 테스트로 두지 않습니다
- [ ] `make verify`가 통과한다
