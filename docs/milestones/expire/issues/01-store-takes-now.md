# 01: store가 "지금"과 만료 시각을 받도록 바꾼다

**Status:** ready-for-agent

**What to build:** store의 저장, 조회, 삭제가 부르는 쪽이 넘긴 "지금"(ms)을 받고, 저장은 만료 시각이나 "만료 없음"도 받습니다. 이 티켓은 동작을 바꾸지 않습니다. api 층과 M1·M2의 테스트는 "만료 없음"과 아무 시각을 넘기도록 호출부만 고칩니다. 시그니처 변경이 테스트 여러 곳에 퍼지므로, 이 변경을 먼저 끝내야 다음 티켓의 diff에 동작 변화만 남습니다. 결정은 `../spec.md`의 "store와 시각"을 따릅니다.

**Blocked by:** None (can start immediately)

테스트 시나리오(팀 확인). 테스트 이름은 아래 문장을 그대로 씁니다.

- [x] 만료 없이 저장한 key는 아주 먼 시각에 조회해도 value를 돌려준다

그 밖의 완료 조건:

- [x] "만료 없음"을 나타내는 값의 이름을 정하고, 그 이름을 `CONVENTION.md`의 이름 표에 더할지 정한다
- [x] M1·M2·M3의 기존 테스트가 호출부만 바뀐 채로 모두 통과한다
- [x] store는 시계를 직접 읽지 않는다
- [x] `make verify`가 통과한다
