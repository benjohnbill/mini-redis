# 05: 세 시나리오로 S와 K를 재고 기본값을 고른다

**Status:** ready-for-agent

**What to build:** 측정하는 팀원은 `make bench`로 주기 청소의 간격 S, 한 번의 상한 K, 루프의 대기 시간 `POLL_INTERVAL_MS`를 조합마다 다시 빌드해 잽니다(Q19). 시나리오는 "한꺼번에 만료"(key 10만 개가 같은 만료 시각), "꾸준한 만료"(초당 1,000개씩 만료), "큰 value의 만료"(16 MiB value 여러 개가 같은 순간에 만료) 세 가지이고(Q20), M3처럼 작은 GET을 정해진 시각마다 보내면서 작은 GET의 p99와, 만료된 key가 만료 시각 뒤에 얼마나 남았는지를 함께 잽니다. 세 시나리오 모두에서 p99가 10 ms 이하인 조합 가운데 만료된 key가 가장 짧게 남는 조합을 기본값으로 고릅니다(Q21). 결정은 `../spec.md`를 따릅니다.

**Blocked by:** 04
